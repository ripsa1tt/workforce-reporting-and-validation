# workforce-reporting-and-validation
An independent Talent Acquisition analytics project exploring workforce reporting, data validation and automation using R and Excel.

# Project Overview
I created two synthetic datasets representing a hiring plan and recruitment activity to explore how data discrepancies could be identified automatically and how workforce metrics could be reported in Excel.

# What I Built
- Synthetic workforce datasets using R.
- Data reconciliation using INDEX-MATCH, COUNTIF and conditional formatting in Excel.
- Six automated data validation checks in R.
- An exception report identifying records requiring review.
- An Excel dashboard using Power Query, PivotTables, formulas and charts.

# Testing
I tested the workflow by updating an outdated recruitment record, rerunning the R scripts and refreshing Excel. The number of exceptions decreased from six to five, and the dashboard updated accordingly.

All data and business rules are fictional. This project was developed as an AI-assisted learning exercise to explore workforce analytics and reporting automation.
